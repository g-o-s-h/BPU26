- 全局变量声明 Declare a Global Variable
    全局变量：跟随整体代码的变量，从代码中的第一个赋值开始，到运行完消失
    局部变量：某一个代码块内使用的变量，从代码块内被定义（第一次赋值）开始，到这个代码块结束消失

```py
a = 1

def first():
    global a
    print(a)
```

- 递归 & 递推 —— 优劣分析 The pros & cons of Recursion & Recurrence

    递归：
    - 容易爆栈（stack overflow），待处理的问题堆的太多
    - 运行时间长

    - 代码可读性强
    - 逻辑清晰，方便编写

    递推：
    - 效率高，速度快
    - 占的内存少（变量反复使用）

    - 有时候可读性很差（譬如
    ```py
    while a % b != 0:
        a, b = b, a % b
    ```
    - 逻辑很容易把自己绕进去，需要特意设计迭代
