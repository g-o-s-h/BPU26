- 布尔运算符 Boolean Operators

```py
<  # 小于
<= # 小于等于
>  # 大于
>= # 大于等于
== # 等于
!= # 不等于

if a = 1:  # 错误的
if a == 1: # 正确的

and # 与 *
or  # 或 +
not # 非

1 = True
0 = False

```

- 布尔（条件）表达式 Boolean Expression

```py

a = 10
a > 0 and a < 100 = True
a > 15 and a < 50 = False

1 and 1 = 1
1 and 0 = 0
0 and 1 = 0
0 and 0 = 0

1 or 1 = 1
1 or 0 = 1
0 or 1 = 1
0 or 0 = 0

not 0 = 1
not 1 = 0
```

- 选择语句 If-elif-else

```py
if a > 1:
    print("a is bigger than 1")
elif a > -1:
    print("a is bigger than -1, but smaller than 1")
else:
    print("other situations")
```
