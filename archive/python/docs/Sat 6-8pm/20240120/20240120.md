# 打印图形 Pattern

## 第一题
输入：`n`  
输出：`n` 行，每行 10 个 `'*'`  

样例输入：
```
3
```
样例输出：
```
**********
**********
**********
```

## 第二题
输入：`n`  
输出：`n` 行，每行一个数，从 `1` 到 `n`

样例输入：
```
3
```
样例输出：
```
1
2
3
```

## 第三题
输入：`n`  
输出：`n` 行，每行 `n` 个 `'*'`

样例输入：
```
3
```
样例输出：
```
***
***
***
```

## 第四题
输入：`n`  
输出：`n` 行，每行 `i` 个 `'*'`，`i` 从 `1` 到 `n` 递增

样例输入：
```
3
```
样例输出：
```
*
**
***
```
