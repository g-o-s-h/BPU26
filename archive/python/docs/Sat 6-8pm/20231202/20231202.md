```
>>> nums = [10, 20, 30, 40, 50, 60, 70, 80, 90]
>>> nums[2:7]
[30, 40, 50, 60, 70]
>>> nums[:7]
[10, 20, 30, 40, 50, 60, 70]
>>> nums[4:]  
[50, 60, 70, 80, 90]
>>> nums[::2]
[10, 30, 50, 70, 90]
>>> nums[::-1] 
[90, 80, 70, 60, 50, 40, 30, 20, 10]
```
