- 计数循环 For

从 1 到 100，
能被 3 整出输出 Fizz
能被 5 整出输出 Buzz
能被 15 整出输出 FizzBuzz
否则输出那个数本身
```py
for i in range(1, 101):

    if i % 3 == 0 and i % 5 == 0:
        print("FizzBuzz")

    elif i % 3 == 0:
        print("Fizz")

    elif i % 5 == 0:
        print("Buzz")

    else:
        print(i)
```

依次输出 0 到 10^10 - 1 的每一个数
```py
n = 10

for i in range(n ** 10):
    print(i)
```

- 遍历循环 For-each

遍历
```py
list1 = [4, [16, 27], 5.6, "鸡汤来喽", 114514]

# 这是 for each
for i in list1:
    print(i)

# 这是 for（作为对比）
for i in range(10):
    print(list1)
```

- 嵌套循环

```py
for i in range(10):
    for j in list1:
        print(j)
```
