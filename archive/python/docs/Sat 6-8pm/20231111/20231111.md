## 今天的内容

（下）
- 多元赋值 Multi-Assignment
```py
a, b = 5, 3
# 等价于
a = 5
b = 3
```

- 顺序结构 Sequential Structure
顺序结构从上往下依次执行每一行代码

- 输入 Input
```py
a = input()
# 输入 18，a 变成 '18'
# '18' 不是整数（Integer）类型
# 而是字符串（String）
```

- 输入处理 Input Process
```py
a = int(input())
# 等价于
a = input()
a = int(a)
```

- 输出 Print
```py
print(18)
# 18

a = 10
print(a)
# 10

print('a')
# a

print('hello world')
# hello world
```

- 函数 & 方法 Functions & Methods
```py
help(print)

a = print(10)

print(a)
# None

print(10, 20, 30, 100, 200, sep = ', ', end = '\n\n')

# 函数名：print

# 参数：
# 10
# 20
# 30
# 100
# 200
# 特殊参数
# sep = ', '
# end = '\n\n'

# 返回值：None

# 其他效果：在屏幕上显示
# 10, 20, 30, 100, 200
# 


def sum(a, b):
    return a + b

s = sum(1, 2)
```

- 类型转化 & 变量储存方式 Type Conversion & Storage method of Variables
```py
# 转换成整数 Integer
a = int(a)
# 转化成小数 Float（浮点数）
a = float(a)
# 转换成布尔型 Boolean（真 or 假）
a = bool(a)
# 转换成字符串 String
a = str(a)

# 弱类型
a = 10
a = 100.0
a = 'hello world'
```
