## 推导式（主要用于输入）

- python 的输入处理（其实超纲了，但刷题又不得不面对
    - 通过多元赋值 multi assignment  
      形如 `a, b = input().split()`  
    - 通过推导式构建 list  
      形如 `numbers = [i for i in input().split()]`  
    - 简单讲一下 split（其实是 第四部分-字符串 的内容）

## for - else

for
里面有 if
里面有 break（终止循环 / 退出循环）
else（如果整个循环结束，没有触发 break，就执行 else）

吃的不是一个 if 的剩饭，而是整个 for 循环的剩饭

## while 当型循环

```py
while <条件>:
    <代码>

# 死循环
while True:
    print("鸡你太美", end = "")
    # 额外的退出方法
    # if xxx:
    #     break
```
