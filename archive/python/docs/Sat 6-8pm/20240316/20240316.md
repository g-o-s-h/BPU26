# 字符串

## 输出格式化

- 手动调整
    ```py
    a = int(input())
    b = int(input())
    print(a, "+", b, "=", a + b)
    ```

- 格式串 + %
    ```py
    print("%d + %d = %d" % (a, b, a + b))

    # 四舍五入
    print("%.2f" % number)
    print(round(number, 2))
    ```
    - %d integer 整数
    - %f float 浮点数
    - %s string 字符串

- str.format() 方法
    ```py
    print("{a} + {b} = {result}".format(
        a = a,
        b = b,
        result = a + b
    ))
    ```

- f string（f 串）
    ```py
    print(f"{a} + {b} = {a + b}")
    ```
