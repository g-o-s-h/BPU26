## 2 选择结构 Boolean Structure (2)

- 布尔型 Boolean Type
    - 真 True  1
    - 假 False 0

- 布尔运算符 Boolean Operators

    - 布尔比较符
    ```py
    >   # 大于
    <   # 小于
    >=  # 大于等于
    <=  # 小于等于
    ==  # 等于
    !=  # 不等于
    ```

    - 布尔逻辑符
        - 与 and
            我要 苹果 *和* 汉堡
            苹果 True
            汉堡 True
            结果才是 True
            1 and 1 = 1
            0 and 1 = 0
            1 and 0 = 0
            0 and 0 = 0
            and 和乘法运算规律相同

        - 或 or
            我要 苹果 *或者* 汉堡
            苹果 和 汉堡只要出现一个 就可以
            1 or 1 = 1
            0 or 1 = 1
            1 or 0 = 1
            0 or 0 = 0
            and 和加法运算规律相同
            （由于 bool 的最大值就是 1，所以 1 + 1 = 1）

        - 非 not
            not 1 = 0
            not 0 = 1
            非黑即白

- 布尔（条件）表达式 Boolean Expression
```py

a = 10
a > 0 and a < 100 = True
a > 15 and a < 50 = False

1 and 1 = 1
1 and 0 = 0
0 and 1 = 0
0 and 0 = 0

1 or 1 = 1
1 or 0 = 1
0 or 1 = 1
0 or 0 = 0

not 0 = 1
not 1 = 0
```

```bash
>>> bool(100)
True
>>> bool(1)
True
>>> bool(0)
False
>>> bool(None)
False
>>> bool('\0')
True
>>> bool("")
False
>>> bool()
False
```

- 选择语句 If-elif-else

```py
if a > 1:
    print("a is bigger than 1")
elif a > -1: # else if
    print("a is bigger than -1, but smaller than 1")
else:
    print("other situations")
```
