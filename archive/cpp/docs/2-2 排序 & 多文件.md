## 函数的预先声明

这个能运行吗？
```c++
int main() {
    int number1, number2;
    std::cin >> number1 >> number2;
    std::cout << sum(number1, number2);
}

int sum(int a, int b) {
    return a + b;
}
```

加上预先声明
```c++
int sum(int a, int b);

int main() {
    int number1, number2;
    std::cin >> number1 >> number2;
    std::cout << sum(number1, number2);
}

int sum(int a, int b) {
    return a + b;
}
```

- 延伸：函数的重载 (overload：重载，超载)
    多个函数共用同一个名字，但他们的参数列表的变量类型不同，返回值不一定相同

```c++
int sum(int a, int b);
// int sum(int number, int number2);
int sum(int a, int b, int c);
int sum(int a, int b, int c, int d);
int sum(int arr[]);
int sum(std::vector<int> v);
std::string sum(std::string a, std::string b);

int main() {
    sum(1, 2);
    // line 58

    sum(1, 2, 3);
    // line 59

    sum(1, 2, 3, 4);
    // line 60

    int arr[] = {1, 2, 3};
    sum(arr);
    // line 61

    std::vector<int> v = {1, 2, 3};
    sum(v);
    // line 62

    std::string a = "123", b = "abc";
    sum(a, b);
    // line 63
}
```

## 头文件的注意事项

- define guards / pragma once ?
`header_file.h`
```c++
#ifndef _NAME_NAME_NAME_ // if _NAME_NAME_NAME_ is not defined
#define _NAME_NAME_NAME_ // define _NAME_NAME_NAME_
                         // else 什么也不做

#include <iostream> // 头文件引用大家都会用到的库

namespace mySpace {
    
    // 一堆函数的定义

}

#endif // _NAME_NAME_NAME_
// 这里的注释是要标记 endif 到底 end 了哪个 if
//（如果你有很多个 #ifdef 和 #ifndef，不标记容易混淆）

// 这一举措是为了保证 “一堆函数的定义” 只执行一次，避免重复定义
```

## 源文件的注意事项

`source_file.cc`
```c++
#include "header_file.h" // 引用自己的头，如果源文件太长可以拆成好几分，但只有一个头（一头多源）

#include <algorithm> // 源文件引用只会在这段代码使用的库（因为其他文件不会共享这些内容）

namespace mySpace {

    // 一部分函数的实现

}
```
