## 乘方

std::pow是C++标准库中的一个函数，用于计算一个数的幂。它接受两个参数，第一个参数是底数（base），第二个参数是指数（exponent），返回底数的指定次幂的结果。

例如，使用std::pow计算2的3次幂可以这样写：

```cpp
#include <cmath>
#include <iostream>

int main() {
    double base = 2.0;
    double exponent = 3.0;
    double result = std::pow(base, exponent);
    std::cout << "2^3 = " << result << std::endl;

    return 0;
}
```

输出结果为：

```
2^3 = 8
```

需要注意的是，std::pow函数返回的是一个浮点数类型的结果，如果需要整数类型的结果，可能需要进行类型转换。
