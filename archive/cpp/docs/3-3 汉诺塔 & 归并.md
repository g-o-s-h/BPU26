## 汉诺塔 Hanoi Tower

输入 n，代表 n 层（n 个盘子）的汉诺塔

初始情况：所有盘子都在最左边的柱子 A 上

任务：需要借助中间的柱子 B，将所有盘子挪到柱子 C 上

（简单）输出 需要花费的步数

（困难）输出 每一步该怎么走


1盘 1步
A->C

2盘 3步
A->B
A->C
B->C

3盘 7步
A->C
A->B
C->B

A->C

B->A
B->C
A->C


n盘 2^n-1步


如何将一个盘子从 A 通过 B 移到 C

把上方若干个盘子从 A 移到 B 中转
把目标盘子从 A 移到 C
把 B 的若干盘子移到 C
