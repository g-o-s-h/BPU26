## 辗转相除法 20min
求最大公约数

【输入】a 和 b  
```
114 514
```

【输出】一个数 x，表示 a 和 b 的最大公约数  
```
2
```

【样例解释】  
1   114 % 514 = 114  
2   514 % 114 = 58  
3   114 % 58  = 56  
4   58  % 56  = 2  
5   56  % 2   = 0  

```c++
int main() {
    int a, b, c;
    cin >> a >> b;
    c = a % b; // 114 514 114

    while (c != 0) {
        a = b; // 514
        b = c; // 114
        c = a % b; // 58
    }

    cout << b;
}
```
