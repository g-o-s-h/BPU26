- 三种传参类型

C++ 函数传参有几种方式，包括传值、引用和指针。它们在参数传递过程中的机制和效果有所不同。

1. 传值（pass by value）：
   在传值方式中，实参的值被复制到函数的形参中。这意味着函数内部对形参的修改不会影响到实参本身。

2. 引用传递（pass by reference）：
   通过引用传递方式，形参是实参的引用。这样，在函数内部对形参的修改会直接反映到实参上。使用引用传递可以避免拷贝大型对象的开销，并且使得函数可以修改实参的值。

3. 指针传递（pass by pointer）：
   使用指针传递方式，形参是实参的指针。通过指针可以间接地修改实参的值，并且可以在函数内部动态分配内存。类似引用传递，指针传递也可以避免拷贝对象的开销。

它们的区别主要在于对实参的修改是否会影响原始对象，以及在内存使用和效率方面的差异。具体选择哪种方式取决于需要达到的目标。

需要注意的是，在使用引用传递和指针传递时，要确保传入的参数不为 nullptr，以避免出现空指针异常。此外，在使用引用传递时，如果不需要修改实参的值，可以将形参声明为常量引用，以避免意外修改。


- 引用和指针的区别

引用和指针是C++中两种不同的方式来处理变量的别名。它们在使用上有几个区别：

1. 空值（NULL）：指针可以为空，即指向空地址（nullptr），而引用必须始终引用一个对象，不能为NULL。

2. 初始化：指针可以在声明后再进行初始化，也可以先声明再赋值，甚至可以不进行初始化（但不推荐），引用必须在声明时进行初始化，一旦初始化后就不能再引用其他对象。

3. 重新赋值：指针可以通过改变其指向的地址来重新赋值，而引用在初始化后不能再引用其他对象，相当于一个固定的别名。

4. 空间占用：指针需要额外的内存来存储地址值，而引用不需要额外的内存，它只是被绑定到了已经存在的对象上。

5. 操作符：指针通过解引用操作符`*`来访问所指向的对象，而引用不需要解引用操作符，直接使用引用名就可以访问引用对象。

指针可以是常量，即指针本身的值不能被修改，但它可以指向不同的对象。这种情况下，使用`const`关键字修饰指针类型。例如：`const int* ptr`表示指向常量的指针，即指针指向的对象不能通过指针修改；`int* const ptr`表示常量指针，即指针本身的值不能被修改。而引用没有常量的概念，它总是指向同一个对象，不能重新绑定到其他对象上。如果需要指向常量对象，可以使用常量引用，如`const int& ref`。


- 修饰符的选择

函数传参的修饰符的选择取决于具体的需求和使用场景。下面是一些常见情况的建议：

1. 不修饰：
   当参数在函数内部需要被修改，并且对原始对象的修改是期望的时候，不需要使用修饰符。

2. const 修饰：
   当参数在函数内部不需要被修改，并且对原始对象的修改不是期望的时候，应该使用 const 修饰。这样可以防止意外的修改，并提高代码的可读性。

3. static 修饰：
   static 关键字用于修饰局部变量时，会使该变量在多次函数调用之间保持其值不变。这在需要保持状态或计算一次结果并在后续调用中重用时非常有用。在函数参数传递中，一般不使用 static 修饰。

4. static const 修饰：
   当参数既希望在多次函数调用之间保持其值不变，又不希望在函数内部被修改时，可以使用 static const 修饰。这样可以确保参数的值在函数调用之间保持不变，并防止对其进行修改。

除了上述修饰符外，还有其他一些修饰符，如引用（&）、指针（*）、volatile 等，它们的使用与具体的需求和语义相关。例如，使用引用可以避免拷贝大型对象的开销，使用指针可以灵活处理传递空值的情况，使用 volatile 可以标记变量在多线程或异步环境中可能发生变化等。

总之，在选择修饰符时，应该根据参数的目的、需求和语义来进行选择，并遵循代码清晰、可维护和可读性的原则。
