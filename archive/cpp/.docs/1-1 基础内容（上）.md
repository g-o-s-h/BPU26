## 第一个代码

新建代码 `helloworld.cpp`
```c++
#include <iostream>
using namespace std;

int main() {
    cout << "Hello world!" << endl;
    return 0;
}
``` 
在终端里先输入 “g++ 编译指令”
```
g++ helloworld.cpp -o helloworld.exe
```
再输入可执行文件的名字
```
helloworld.exe
```
就可以直接观察结果了

## 注释

注释 **不是** 代码的一部分！  
注释是写给人看的，代码则是写给计算机看的。    
注释的内容 **不会被执行**！  

```c++
// 这是一个单行注释
// cout << "这是一段被注释掉的代码，它不会工作";
/* 这是一段注释 */
/*
多行注释
可以横跨
很多行
*/
```

**请不要随意使用多行注释**  
无论是注释代码 or 写备注，尽量用单行注释

在 `VSCode`，你可以选中多行，按住 `Ctrl`+`/` 一键注释/取消注释

下面是添加注释后的 `helloworld.cpp`
```c++
#include <iostream>  // 连接标准 I/O 流
using namespace std; // 使用 std 命名空间

int main() { // 主函数
    // 输出 Hello world!
    cout << "Hello world!" << endl; 
    return 0; // 无错误地结束本程序
}
```

## 运算符 & 目数

目数，指一个 **运算符** 需要多少个 **数** 来参与计算。  
数学中的四则运算 `+ - × ÷` 是 **双目**运算符，他们一次运算影响两个数。

以后我们还会遇到只带一个数的 **单目**运算符、一次运算带三个数的 **三目**运算符，等等。

与数学不同，`C++` 有着自己的七则运算。

|符号|运算|
|:-|:-|
|`a + b`|加法|
|`a - b`|减法|
|`a * b`|乘法|
|`a / b`|除法|
|`a % b`|求余|
|`a++` or `++a`|自增|
|`a--` or `--a`|自减|

\* *正常情况下，除法结果一定是浮点数（小数）*  
\* *如果除法两边都是整数，则进行整除运算，结果为整数*

## 变量

变量有自己的名字，可以是 `a`，可以是 `b`，也可以是 `name`，这是**变量名**。

**变量名只能以字母开头！**

变量可以储存一个值，可以是整数 `100`，可以是小数 `3.14`，也可以是 `false` (假)。  
（后面会讲“值”的类型）

值可以通过**赋值语句**改变，每次参与运算的时候，直接用变量的值进行运算。

|关键字|类型|例子|

## 定义

在使用一个变量前，你 **必须** 定义它。  
下面提供两种定义方法：
```
类型 变量名;
类型 变量名 = 初始值;
```
举个例子 `self_intro.cpp`
```c++
#include <iostream>
using namespace std;

int main() {

    // 先定义，再赋值
    int age;
    age = 18;

    // 直接初始化
    double height = 187.5;
    string name = "Wumian_Tony";
    bool gender = 1;

    // 输出
    cout << "My name is " << name << ". ";
    cout << "I'm " << age << ". ";
    cout << "My height is " << height << "cm. ";
    cout << "I'm a " << (gender == 1 ? "boy" : "girl") << ". ";
}
```

## 表达式

就是一堆运算。

举几个例子：  
```
1 + 1 * 3  
a * 2
(b + 5) * c
```

表达式总会有一个**值**！  
程序运行的时候，会计算表达式的值，并用这个值替代表达式本身。

举例：  
1. 表达式 `1 + 1 * 3` 在运行的时候，求出来是 `4`，就被替换成 `4`  
2. `x` 现在等于 `1`，那么表达式 `x * 2 + 1` 在运行的时候，求出来是 `3`，就被替换成 `3`

## 赋值

```c++
变量名 = 一个值 或者 一个表达式;
```  
功能：将等号右边的值存入左边的变量

举个例子：  
```c++
x = 1;
y = x * 3;
```
这段代码先把 `x` 赋值成 `3`，再把 `y` 赋值成 `x * 3`，代入 `x` 被替换成 `1 * 3`，也就是 `y` 被赋值成 `3` 了。

---
## 自赋值

当一个变量的赋值跟自己有关时，我们可以使用自赋值。

举个例子：  
`x = x + 10` 让 x 自己加一
可以简写为 `x += 10`

同理，
- `a += b` 等价于 `a = a + b`
- `a -= b` 等价于 `a = a - b`
- `a *= b` 等价于 `a = a * b`
- `a /= b` 等价于 `a = a / b`
- `a %= b` 等价于 `a = a % b`

再举个例子：
```c++
int a = 101;
a %= 2; // 等价于 a = a % 2
cout << a; // 输出结果是：1
```

## 自增 & 自减

先举例子 `unary_op.cpp`
```c++
#include <iostream>
using namespace std;
int main() {
    int a = 10;
    cout << a << " " << a++ << " " << a << endl;

    int b = 10;
    cout << b << " " << ++b << " " << b << endl;

    int c = 10;
    cout << c << " " << c-- << " " << c << endl;

    int d = 10;
    cout << d << " " << --d << " " << d << endl;
}
```
