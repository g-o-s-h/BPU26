知识目录

添加新知识

手动录入一个知识点，保存后立即出现在知识树里（保存在本机浏览器）。

选择知识点挂在哪个分类下；选"根目录"则作为新的一级分类。

智能整理新知识

粘贴你新学到的原始内容（一段话、几个要点、一段代码都行），让程序帮你整理成结构化知识点。

当前已联网，可用 AI 接口自动整理
本机整理：按行/段落切分要点，提取首句作为标题，生成结构化的新知识点。完全离线，不联网。
需要先在「设置」里配置一个 AI 接口地址（OpenAI 兼容格式）。未配置或离线时，会自动退回本机整理。
整理结果预览（可勾选保留）：

导入整理好的知识点

把「豆包」帮你整理的结构化文本粘贴进来，或粘贴备份 JSON，合并到本知识树。

格式：# 所属分类（可选）→ 标题: xxx → 内容多行 → 下一条用 --- 分隔。
用「导出」得到的 JSON 可直接粘回来，恢复全部笔记与复习进度。

AI 接口设置

配置 OpenAI 兼容的对话接口地址与密钥，用于联网自动整理。不配置也可正常使用（本机整理 + 手动添加）。
