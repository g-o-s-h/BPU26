选修：基础的排序算法

排序需要用到
函数 swap(a, b)
就是把 a 和 b 的值互换

swap也有两种替代方式，也适用于多个数交换
一种是类似小学的 “火车三岔路” 问题：
a = 1
b = 2

a = b
b = c

另一种是通过和差来交换：
a = 1
b = 2

a = a + b
b = a - b

下面是排序算法

比较排序（通过两个数比较，来排序）

# 初始化一个 list
numbers = []

# 输人
length = int(input())
for i in range(length):
	temp = int(input())
	numbers.append(temp)
	# 这句可以简化为 numbers.append(int(input()))

# 排序 (结果是从小到大)
for i in range(0, length - 1):
	for j in range(i + 1, length):
		if numbers[i] > numbers[j]:
			swap(numbers[i], numbers[j])

# 输出，可以直接 print(numbers)，但是这里采用循环输出
for i in range(length):
	print(numbers[i], end = " ")

RE Regular Expression 正则表达式 -------------------------------


r""				代表一个正则表达式，双引号里是匹配内容

方括号匹配 []
"[ABC]"			是 A, B, 或者 C
"[^ABC]"		不是 A, B, 也不是 C
"[A-Z]"			是从 A 到 Z 之间任意一个字母，inclusive
"[^A-Z]"		不是从 A 到 Z 之间的任意一个，inclusive
"[A-Lc-eh-k]"	展开就是 "[ABCDEFGHIJKLcdehijk]"

"[.]"			除了换行符（"\n", "\r"）以外任意字符，等价于 "[^\n\r]"
"[\s\S]"		匹配所有字符，小 s 能代指所有空白符号，包括换行符
				大 S 能匹配任意非空符号，两者加起来覆盖所有字符 
"[\w]"			字母、数字、下划线，相当于 "[A-Za-z0-9_]"


转义字符 \
"\特殊字符"		匹配特殊字符本身，而非其所指的特殊含义
"\c一个字符"		控制字符，runoob 例子：
				"\cM" 匹配 Ctrl-M（组合键） 或者 回车符 "\r"，
				一个字符须在 [A-Za-z] 范围内
				否则，"\c" 视为 "c"，一个字符视为字符本身

"\f"			换页符 等价于 "\x0c" 或 "\cL"
"\n"			换行符 等价于 "\x0a" 或 "\cJ"
"\r"			回车符 等价于 "\x0d" 或 "\cM"
"\t"			制表符 等价于 "\x09" 或 "\cI"，平时按 Tabulator键 触发
"\v"			垂直制表符 等价于 "\x0b" 或 "\cK"

"\s"			一个空白符号 等价于 "[\f\n\r\t\v]"
"\S"			一个非空符号 等价于 "[^\s]"


特殊字符
"$"				只从字符串最末尾匹配 RE串
"*"				对星号前一位字符匹配 0 到 无限 次
"+"				对加号前一位字符匹配 1 到 无限 次

"[]"			方括号匹配表达式

"\字符"			转义字符
